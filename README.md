# auditargvio

Audit digests and argv fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/auditargvio/

## Install / run

```bash
git clone https://github.com/theworker02/auditargvio.git
cd auditargvio
node src/cli.js
node --test
```
